ONLINE COURSE – COURSE ENROLLMENT

Project Description

This project represents an Online Course – Course Enrollment System for a BCA college assignment.

The system manages:

- Student Details
- Course Details
- Instructor Details
- Enrollment
- Enrollment Status

Main Features

1. Student Details

The system stores:

- Student ID
- Name
- Email
- Phone
- Department

2. Course Details

The system contains:

- Course ID
- Course Title/Name
- Description
- Credits
- Duration

3. Instructor Details

The system stores:

- Instructor ID
- Name
- Email
- Phone
- Department

4. Course Enrollment

The system checks prerequisites and course/seat availability before enrollment. An Enrollment ID and Enrollment Date are generated when the enrollment is recorded.

5. Enrollment Status

The enrollment status can be:

- Pending
- Enrolled
- Rejected

Flowchart

ER Diagram

The ER diagram contains four main entities:

- STUDENT
- COURSE
- INSTRUCTOR
- ENROLLMENT

It also shows primary keys, relationships, and appropriate cardinalities.

System Flow

START → Student Details → Course Details → Select Course → Check Instructor/Prerequisites/Seat Availability → Decision → Enrollment → Update Enrollment Status → Display Enrollment Details/Status → END

Purpose

The purpose of this project is to demonstrate the basic design of an Online Course Enrollment System using an algorithm, flowchart, and ER diagram.
